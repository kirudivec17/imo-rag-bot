# 🚢 IMO RAG Bot - Hong Kong Convention & ISPS Assistant

An open-source AI assistant for **Safe & Environmentally Sound Ship Recycling** and **Maritime Security**.

Ask in Hinglish: "Cybutryne ka limit?", "SRP me kya chahiye?", "Flag ko kab notify karna hai ISPS pe?"

### 📚 Data Source - 100% Legal & Public
This repo DOES NOT contain copyrighted IMO books. We use only free IMO Resolutions & Circulars from imo.org:

**Hong Kong Convention - 7 Official Guidelines (COMPLETE):**
- MEPC.196(62) SRP, MEPC.210(63) Safe Recycling, MEPC.211(63) Facility Auth
- MEPC.222(64) Survey & Certification, MEPC.223(64) Inspection (PSC)
- MEPC.379(80) + MEPC.405(83) - IHM + Cybutryne 200mg
- HKSRC.2/Circ.1 (2024) - Basel & HKC Transboundary

**Maritime Security:**
- SOLAS XI-2 + ISPS Code, MSC/Circ.1097, MSC.1/Circ.1191, ILO/IMO Port Security Code
- Total: 17 Docs | 5500+ Chunks | 400% Bulletproof

### How it Works?
BYOD Model - Code is mine, Data is yours (like Pranjali's project). Upload your legally obtained free PDFs in data/ folder. Code chunks with LangChain 1000/200 and searches with ChromaDB + Gemini with source page numbers.
