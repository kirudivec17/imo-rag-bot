# ⚓ HKC Intelligence Platform

**Ship Recycling Compliance | IMO Standards & Guidelines**

Professional intelligence platform for Hong Kong Convention (HKC) implementation, Inventory of Hazardous Materials (IHM), and Ship Recycling Plan (SRP) compliance.

### Features
- **AI Assistant** powered by `gemini-2.5-flash`
- **Document Library** - 10 Parts Master IMO Corpus (Public IMO Docs)
- **Citation-Based Answers** - Every answer with Source & Relevance Score
- **Standards Covered:**
    - Hong Kong Convention (HKC)
    - MEPC.196(62) - IHM Guidelines
    - MEPC.197(62) - SRP Development
    - MEPC.379(80) - Cybutryne & Anti-fouling
    - Safe and Environmentally Sound Recycling

### Tech Stack
- Streamlit UI
- TF-IDF N-Gram Retrieval (20k features)
- Google GenAI - Gemini 2.5 Flash (Primary Model)

### Usage
Ask questions like:
- How to prepare SRP as per MEPC.196(62)?
- What is IHM Part I requirement?
- Cybutryne limits under HKC?
